# Security Policy

## Official Versions

Only versions published through this repository and the project's official distribution channels should be considered official releases of this software.

Third-party forks, modified builds, repackaged versions, or copies distributed through unofficial channels are not controlled, reviewed, or endorsed by the original author.

If you obtained this software from an unofficial source, verify its origin before running it.

## Reporting a Security Vulnerability

If you discover a security vulnerability in the official version of the software, please report it privately to the project maintainer instead of publicly disclosing the vulnerability.

When reporting a vulnerability, please include:

* A description of the vulnerability.
* Steps to reproduce the issue.
* The affected version.
* Any relevant screenshots, logs, or proof of concept.
* Information that may help reproduce or investigate the issue.

Please do not include passwords, private keys, personal information, or other sensitive data in the report.

## Malicious or Unauthorized Modifications

The original author is not responsible for modifications made by third parties.

Versions containing malware, spyware, backdoors, malicious code, or other unauthorized modifications are not official releases of this project.

If you encounter a suspicious version claiming to be an official release, please report it to the project maintainer with information about where it was obtained.

## Security Updates

Security issues affecting official releases may be addressed through a new release or security update.

Users are encouraged to obtain updates directly from the official project repository or other official distribution channels.
